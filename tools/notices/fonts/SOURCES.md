# Font licence texts for fonts bundled by `typst-assets`

The `typst-assets` crate embeds these fonts without their licence files. The texts were downloaded
on 2026-10-30 from each font's upstream project and are copied verbatim into
`THIRD_PARTY_NOTICES.txt` by `tools/notices/generate.mjs`.

| File                    | Font                                  | Source                                                                 |
| ----------------------- | ------------------------------------- | ---------------------------------------------------------------------- |
| `OFL-Libertinus.txt`    | Libertinus Serif                      | https://raw.githubusercontent.com/alerque/libertinus/master/OFL.txt    |
| `GUST-FONT-LICENSE.txt` | New Computer Modern 10, NewCM Math    | https://www.gust.org.pl/projects/e-foundry/licenses/GUST-FONT-LICENSE.txt |
| `LPPL-1.3c.txt`         | (referenced by the GUST Font License) | https://www.latex-project.org/lppl.txt                                 |
| `LICENSE-DejaVu.txt`    | DejaVu Sans Mono                      | https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE       |
| `LICENSE-PDFium.txt`    | Foxit standard PDF fonts (PDFium)     | https://pdfium.googlesource.com/pdfium/+/refs/heads/main/LICENSE       |
