# Third-party licences

Components shipped inside the Maatwerk executable. Rust crates are checked by `cargo deny`
(`deny.toml`), npm packages by `tools/check-npm-licenses.mjs`. This file lists the direct
dependencies and every non-code asset (fonts, Typst packages, images); update it when one is added.

The full licence texts of **everything** shipped in the exe (all ~470 Rust crates, the bundled npm
packages, fonts, Typst packages) are in `THIRD_PARTY_NOTICES.txt`, generated by
`npm run notices` (cargo-about 0.9 + `tools/notices/generate.mjs`). CI fails when it is out of
date, and ships it next to the exe.
